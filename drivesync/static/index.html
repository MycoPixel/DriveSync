Connect a Google account

  1. Open the Google Cloud Console: create a project.
  2. Enable the Google Drive API.
  3. Configure the OAuth consent screen (add yourself as a test user while it is in Testing).
  4. Create credentials → OAuth client ID → Desktop app.
  5. Paste the client ID and secret below, then test the connection.

DriveSync uses your own OAuth client — nothing of yours flows through third-party servers. See the README for a 2-minute walkthrough.
